## Overview

This repository contains a Python Jupyter Notebook for
geospatial analysis and visualization of natural hazard
events in Nepal.

## Tools and Libraries

- Python
- Pandas
- GeoPandas
- Matplotlib
- Shapely
- Requests
- NASA EONET API

## Notebook

`2015earthquakes.ipynb`

## Data Sources

- NASA Earth Observatory Natural Event Tracker (EONET)
- Nepal administrative boundary shapefile

## Requirements

Python 3.x

Install dependencies:

```bash
pip install requests pandas geopandas matplotlib shapely
```

## How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Provide the Nepal district boundary shapefile.
4. Open the notebook using Jupyter Notebook or Google Colab.
5. Execute the notebook cells.
